# 勒忒洞窟

## 概览

| 项目 | 内容 |
| --- | --- |
| 进入方式 | 从德尔斐经「德尔斐—勒忒洞窟引路线」步行前往 |
| 单程耗时 | 约 4 小时 |
| 往返险情 | 约 27% |
| 路途风险 | 黑暗失足与迷向、洞中恍惚与记忆错乱 |
| 可采资源 | 生水（采集需随身携带一枚冥河钱） |
| 公共火源 | 无 |
| 当地食物 | 无直接可取的食物来源 |

## 补给准备

| 项目 | 数量 |
| --- | --- |
| 往返安全水 | 约 3 瓶 |
| 往返口粮 | 约 2.5 份 |

## 注意事项

- 洞内水源不能直接当安全饮用水，需自行处理后才可饮用。
- 无公共火源，失温时须自带火具或遮蔽，否则尽早撤离。
- 洞内的生水采集点需随身携带一枚冥河钱才能取用，进入洞窟本身没有此门槛。
- 携带防风雨披衣时，本路线体温流失降低约 25%。
